# Refunds hide Progress instead of deleting it

When a Learner gets a Refund, they lose access to the course but their Progress is kept, hidden, and comes back if they buy the course again. We chose this over deleting Progress because a Refund involves real money: deleting can't be undone, it would erase the record behind an Admin's decision, and it would punish a Learner whose Refund fails or who returns later. The cost is that we keep Progress for courses a Learner no longer owns, so anything reading Progress must check access rather than assume Progress implies ownership.
